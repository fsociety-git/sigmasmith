# Changelog

## 0.1.0 (2026-10-19)

- Ten original Sigma rules with sample-event tests, covering messaging-app malware delivery, SIEM log forwarder tampering, SSH hardening regression, and Tor usage across Windows, Linux, DNS and proxy logs.
- Dependency-free Sigma matcher for CI testing.
- SigmaHQ-convention validator, pySigma compilation to Splunk, Elasticsearch, OpenSearch and Kusto with per-rule pipeline fallback, ATT&CK coverage table, and rule scaffolding.
